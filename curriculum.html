텀 프로젝트 — 작은 모델의 한 모듈 분해

8회차 시점에 주제 확정, 13회차 발표. 스코프는 한 모듈로 한정하여 구현 부담을 낮춥니다. 학생은 다음 5단계를 수행합니다.

  1. 다음 권장 후보 중 하나의 한 모듈만 선택:
    • GPT-Neo 125M의 single attention head 또는 MLP 블록 (HuggingFace 공개)
    • nanoGPT의 한 transformer block (Karpathy 공개, 약 300줄)
    • MiniLSTM의 cell 구조 또는 GRU cell
    • LeNet-5의 한 conv 레이어 (1989, 60K 파라미터)
    • 또는 본 강좌 미니과제 6 후보(BatchNorm·Embedding·LSTM·LoRA·Conv1d·U-Net 등) 중 하나
  2. 선택한 모듈 내 텐서 연산을 표준 LA 객체(행렬곱, 정사영, 고유분해, SVD, Kronecker곱 등)로 환원
  3. 환원 구조를 다이어그램과 수식으로 표현
  4. NumPy로 모듈 재구현 → PyTorch 원본과 출력 일치 검증 (atol=1e-5)
  5. 보고서는 정의·정리 인용을 포함한 학술 형식 (5-10페이지)

Matrix gradient identities reference 표 (10회차 마지막 20분 또는 자료 끝 부록)
식미분
$f(\mathbf{x}) = \mathbf{a}^\top \mathbf{x}$$\nabla_\mathbf{x} f = \mathbf{a}$
$f(\mathbf{x}) = \mathbf{x}^\top \mathbf{x}$$\nabla_\mathbf{x} f = 2\mathbf{x}$
$f(\mathbf{x}) = \mathbf{x}^\top A \mathbf{x}$$\nabla_\mathbf{x} f = (A + A^\top)\mathbf{x}$ (대칭 $A$면 $2A\mathbf{x}$)
$\mathbf{f}(\mathbf{x}) = A\mathbf{x}$$J = \partial \mathbf{f}/\partial \mathbf{x} = A$
$L(\mathbf{w}) = \frac{1}{2}\|X\mathbf{w} - \mathbf{y}\|^2$$\nabla_\mathbf{w} L = X^\top(X\mathbf{w} - \mathbf{y})$
$f(X) = \mathrm{tr}(AX)$$\nabla_X f = A^\top$
$f(X) = \mathrm{tr}(X^\top A X)$$\nabla_X f = (A + A^\top) X$
$f(X) = \det(X)$$\nabla_X f = \det(X) (X^{-1})^\top$
$f(X) = \log\det(X)$$\nabla_X f = (X^{-1})^\top$
체인룰: $\mathbf{z} = g(\mathbf{y}), \mathbf{y} = f(\mathbf{x})$$J_{\mathbf{z}/\mathbf{x}} = J_{\mathbf{z}/\mathbf{y}} \cdot J_{\mathbf{y}/\mathbf{x}}$
