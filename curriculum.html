Matrix gradient identities reference 표 (1회차 또는 자료 끝 부록)
식미분
$f(\mathbf{x}) = \mathbf{a}^\top \mathbf{x}$$\nabla_\mathbf{x} f = \mathbf{a}$
$f(\mathbf{x}) = \mathbf{x}^\top \mathbf{x}$$\nabla_\mathbf{x} f = 2\mathbf{x}$
$f(\mathbf{x}) = \mathbf{x}^\top A \mathbf{x}$$\nabla_\mathbf{x} f = (A + A^\top)\mathbf{x}$ (대칭 $A$면 $2A\mathbf{x}$)
$\mathbf{f}(\mathbf{x}) = A\mathbf{x}$$J = \partial \mathbf{f}/\partial \mathbf{x} = A$
$L(\mathbf{w}) = \frac{1}{2}\|X\mathbf{w} - \mathbf{y}\|^2$$\nabla_\mathbf{w} L = X^\top(X\mathbf{w} - \mathbf{y})$
$f(X) = \mathrm{tr}(AX)$$\nabla_X f = A^\top$
$f(X) = \mathrm{tr}(X^\top A X)$$\nabla_X f = (A + A^\top) X$
$f(X) = \log\det(X)$$\nabla_X f = (X^{-1})^\top$
체인룰: $\mathbf{z} = g(\mathbf{y}), \mathbf{y} = f(\mathbf{x})$$J_{\mathbf{z}/\mathbf{x}} = J_{\mathbf{z}/\mathbf{y}} \cdot J_{\mathbf{y}/\mathbf{x}}$

출처: MML Ch.5.4-5.5, Petersen·Pedersen Matrix Cookbook §2-§9. 외우는 것이 목적이 아니라 유도 패턴을 익히기 위함. 핵심: $\nabla_\mathbf{x}(\mathbf{x}^\top A \mathbf{x}) = (A+A^\top)\mathbf{x}$의 대칭 $A$ 가정 여부를 의식적으로 분리할 것.

행렬 종류조건가능한 분해응용
임의 행렬 $A \in \mathbb{R}^{m\times n}$(모든 경우)SVD: $A = U\Sigma V^\top$데이터 분석·압축 (Eckart-Young)
정방·full rank$A \in \mathbb{R}^{n\times n}$, $\det \ne 0$LU: $A = LU$ (행 교환 없이)선형방정식 풀이
정방·full rank+ 행 교환 필요PLU: $PA = LU$부분 피보팅
대각화 가능정방 + 일차독립 고유벡터 n개고유분해: $A = S\Lambda S^{-1}$거듭제곱·미분방정식
정규(normal)$A A^\top = A^\top A$유니타리 대각화: $A = U\Lambda U^*$양자역학
실대칭 (real symmetric)$A = A^\top$스펙트럼 정리: $A = Q\Lambda Q^\top$공분산·헤시안
양반정치 (PSD)실대칭 + 모든 $\lambda \ge 0$$A = LL^\top$ (Cholesky)다변량 정규 샘플링
양정치 (PD)실대칭 + 모든 $\lambda > 0$Cholesky (유일·강한 보장)손실 헤시안 분석
직교 (orthogonal)$Q^\top Q = I$그 자체로 분해 (회전·반사)Gram-Schmidt·QR
Full column rank$A \in \mathbb{R}^{m\times n}$, $m \ge n$, rank=nQR: $A = QR$최소제곱 안정 풀이
